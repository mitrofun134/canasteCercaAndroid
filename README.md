# Canasta Cerca — Android

Сейчас приложение — **оболочка над сайтом**: один WebView на весь экран открывает Canasta Cerca
(веб-проект `canasta-cerca`, тот же `server.js`). Всё, что умеет сайт, есть и в приложении, а новое на сайте
появляется в приложении само, без новой сборки.

Нативная версия (Compose, Metro, Navigation 3, шесть экранов) лежит в ветке `native`. Она отстаёт от сайта
(корзина на старых полях API) и ещё ни разу не собиралась.

## Запуск

1. В папке сайта: `npm run dev` (сервер на `http://localhost:3000`).
2. Открыть эту папку в Android Studio и запустить `app` на эмуляторе. Эмулятор видит компьютер как `10.0.2.2` —
   это адрес по умолчанию.

Другой сервер задаётся в `~/.gradle/gradle.properties`, **не** в `gradle.properties` проекта: репозиторий публичный.

| Как | Что написать | Камера и «Mi ubicación» |
|---|---|---|
| Эмулятор или телефон по USB | `adb reverse tcp:3000 tcp:3000` и `canasta.baseUrl=http://localhost:3000/` | есть |
| Телефон в той же Wi-Fi | `HOST=0.0.0.0 npm start` и `canasta.baseUrl=http://<IP компьютера>:3000/` | нет (http) |
| Ссылка из `npm run share` | `canasta.baseUrl=https://….trycloudflare.com/` и `canasta.accessKey=<k из ссылки>` | есть |

Камеру и геолокацию браузерный движок даёт сайту только по https и на `localhost`.

Ссылка из `npm run share` меняется при каждом запуске, но пересобирать приложение не нужно: если сайт не открылся,
приложение показывает экран с Firu, и туда можно вставить новую ссылку целиком (с `?k=…`). Она запоминается, пока
в сборке не поменяют адрес сервера.

## Что приложение добавляет к сайту

- **Хранение.** localStorage и cookie сохраняются между запусками: корзина, адрес, способы оплаты, покупки и ключ доступа.
- **Разрешения.** Камера — сканеру штрихкода, геолокация — «Mi ubicación»; системный запрос, только для нашего сайта.
- **Чужие ссылки** (WhatsApp, «Cómo llegar», сайты сетей) открываются в своих приложениях; `window.open` сайта — тоже.
- **«Назад»** листает историю сайта, с первой страницы — выход.
- **Экран «не открылось»**: нет сети, сервер выключен, туннель сменился (5xx) или ключ неверный (401) — «Reintentar»
  и поле для новой ссылки. Тексты ES/RU по языку телефона.
- **User-Agent** дополнен `CanastaCercaAndroid/<версия>`: сервер может отличать приложение от браузера.
- **Отладка.** В debug-сборке сайт внутри приложения виден в Chrome на компьютере: `chrome://inspect`.

## Чего пока нет

- Системного меню «Поделиться»: в WebView нет `navigator.share`, сайт сам предлагает WhatsApp и «скопировать ссылку».
  Картинка «Compartir mi ahorro» не уходит — только текст в WhatsApp.
- Push-уведомлений.

## Сборка

Один модуль `:app`: AGP 9.2.1 (Kotlin встроенный), Gradle 9.6, compileSdk и targetSdk 36, minSdk 26; зависимости —
`androidx.activity` и `androidx.core`. Весь код — `app/src/main/kotlin/ar/canastacerca/MainActivity.kt`,
экран ошибки — `app/src/main/res/layout/activity_main.xml`.
